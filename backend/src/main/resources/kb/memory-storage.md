# 内存和存储怎么选

## 两个容易混的参数

- **运行内存（RAM，如 12GB）**：决定能同时挂多少应用、后台保留多久；
- **存储空间（ROM，如 256GB）**：决定能装多少照片、视频、游戏。

参数表里常写成"12GB+256GB"，前一个是 RAM，后一个是存储。

## RAM 够用的标准

- **8GB**：轻度使用可以，但后台应用容易被杀，切换回来要重新加载；
- **12GB**：目前的主流起点，日常多任务够用；
- **16GB 以上**：重度多开、长期不关应用、或者想用四五年的人更合适。

注意：RAM 不是越大越流畅。系统调度、内存压缩、虚拟内存（把存储当内存用）都会影响体感，
但虚拟内存的速度远低于真实内存，不能靠它替代 RAM。

## 存储要注意类型和速度

- 类型上，UFS 4.x 明显快于 UFS 3.x，体现在安装应用、加载游戏、导出视频；
- 容量上，256GB 是当下比较稳的起点：系统和预装应用会占掉一部分，
  实际可用通常比标称少 20~30GB；
- 经常拍 4K 视频、存无损音乐、装大型游戏，建议 512GB 起。

## 扩展卡还有用吗

绝大多数机型取消了存储卡槽。少数保留的机型也有速度和使用限制
（比如只能存媒体文件、不能装应用）。把扩展卡当"主要扩容手段"不现实。

## 怎么按使用年限选

- 打算用 2 年：12GB + 256GB 足够；
- 打算用 3~4 年：建议 12GB + 512GB，系统和应用的体积都会随时间涨；
- 预算紧张：优先保 RAM（影响日常流畅度），存储不够可以用云盘/定期清理缓解。

## 常见误解

- "RAM 越大跑分越高"：跑分受 RAM 容量影响很小，主要看芯片；
- "存储剩很多就不卡"：卡顿主要来自 CPU 调度、存储随机读写速度和后台；
- "虚拟内存开了就等于加内存"：速度差距很大，只能缓解不能替代。
