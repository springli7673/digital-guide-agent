# 像素高不等于拍照好

## 像素数到底决定什么

像素数决定**照片的分辨率上限**（能放多大、裁切后还剩多少细节），
不决定进光量、不决定噪点、不决定色彩。同样 5000 万像素，
传感器尺寸差一倍，弱光画质可以差一个档位。

## 真正决定画质的四个因素

1. **传感器尺寸**：面积越大，单个像素分到的光越多，弱光噪点越少。
   这是手机影像里最硬的指标，通常用"1/1.3 英寸""1 英寸"这类分数表示。
2. **光圈**：f 值越小进光越多；同尺寸传感器下 f/1.6 明显好过 f/2.0。
3. **算法与调校**：多帧合成、HDR、夜景降噪都是算出来的。
   同一颗传感器，不同厂商出片风格和成片率可以差很远。
4. **镜头素质**：镜片材质、镀膜、是否潜望长焦，决定边缘画质和长焦可用性。

## 高像素的实际用法

高像素模式通常用于两种场景：白天光线充足时输出大图方便裁切；
或者用"像素四合一/十六合一"在暗光下把多个小像素合成一个大像素提高进光量。
所以"2 亿像素"在暗光下拍出来的往往是 1250 万像素的合成图，这不算缩水，是取舍。

## 长焦比主摄像素更值得看

很多机型主摄很强但长焦只有 800 万像素且没有光学防抖，
结果是 5 倍以上全靠数码变焦，拍出来糊。要拍远处，优先看**有没有潜望长焦**、
长焦的传感器尺寸和是否有 OIS。

## 选购时的判断顺序

1. 先看主摄传感器尺寸和光圈；
2. 再看长焦是光学还是数码、有没有 OIS；
3. 然后看超广角是不是凑数（低于 800 万基本只能应急）；
4. 最后才看像素数。

## 常见误解

- "像素越高越清晰"只在光线充足、且放大裁切时成立；
- "DXO 分数高就一定好"不成立，评分侧重不同，风格喜好因人而异；
- "多摄一定比单摄强"，凑数的副摄反而会拖慢对焦和成片速度。
