# 电池容量与续航

## mAh 只是起点

5000mAh 的机器续航不一定比 4800mAh 的长。电池容量是"能存多少电"，
续航是"这些电够用多久"，中间还隔着屏幕、芯片能效和系统调度。

## 真正影响续航的四件事

1. **屏幕功耗**：屏幕通常是第一大耗电项。高刷、高亮度、大尺寸都会明显增加耗电；
   LTPO 这类自适应刷新率能让静态画面降到 1~10Hz，实际省电。
2. **芯片能效**：同样性能，能效差的芯片发热和耗电都更高，5G 或游戏场景差距更明显。
3. **系统调度与后台**：后台唤醒、推送、定位权限管得松，待机耗电会很难看。
4. **充电功率不是续航**：充得快不等于用得久，两者是独立指标。

## 怎么读电池参数

- 容量（mAh）× 电压 ≈ 能量（Wh），大屏旗舰常靠提高电压或双电芯堆容量；
- 双电芯（如 2×2500mAh）在同等体积下能提高充电功率，但结构更复杂；
- 标称容量是典型值，实际可用容量受电池健康度和温度影响。

## 按使用场景估算

- **轻度（微信、刷视频、拍照）**：5000mAh 级别基本能撑一天；
- **重度（游戏、导航、热点）**：看的是持续功耗，建议 5500mAh 以上并关注散热；
- **出差/户外**：优先大电池 + 高功率快充，充电速度能补上容量不足。

## 苹果机型为什么要单独看

iPhone 不公布电池容量（mAh），参数表里这一项是空的。本项目的打分逻辑对缺失维度
按"跳过"处理，所以苹果机型不会因为这一项吃亏，也不会因此虚高——但这也意味着
**续航维度上苹果机型之间无法用 mAh 区分**，只能参考官方标称的视频播放时长。

## 常见误解

- "电池大就一定耐用"：还要看屏幕和芯片；
- "充电快就不怕电池小"：快充解决的是补能速度，不是续航；
- "电池健康度 80% 就要换"：是参考线不是硬线，看实际续航是否明显变差。
