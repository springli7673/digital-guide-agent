# 重量、尺寸与手感

## 为什么重量值得单独挑

手机是长时间握持的设备，重量差 30g 在参数表上不起眼，拿半小时就能感觉出来。
旗舰机堆料（大电池、多摄、均热板）普遍在 210~235g，
轻薄机型通常在 170~190g，代价往往是电池小一点或影像弱一点。

## 影响手感的四个因素

1. **重量**：单手长时间握持，超过 210g 明显更容易累；
2. **宽度与厚度**：宽度比厚度更影响单手操作，宽度超过 76mm 基本要双手；
3. **中框与背板材质**：金属中框 + 磨砂背板摩擦力好，亮面玻璃容易滑；
4. **配重分布**：头重脚轻的机型（大底主摄在上部）握持时更容易"往前坠"。

## 屏幕尺寸与单手操作

- 6.1~6.4 英寸：单手可及，适合通勤单手刷；
- 6.5~6.7 英寸：主流尺寸，双手更舒服；
- 6.8 英寸以上：看视频、玩游戏爽，单手基本不可用。

屏幕尺寸和机身尺寸不是一回事：窄边框能让 6.7 英寸的机器比老款 6.4 英寸还短。

## 轻薄与续航的取舍

轻薄机型通常做三件妥协：电池容量降低、散热面积减小、影像模组缩水。
如果每天重度使用，轻薄带来的舒适可能被"一天两充"抵消。
反过来，如果你主要在家/办公室用、随时能充，轻薄就是纯收益。

## 挑选建议

- 通勤单手用得多：优先 180g 以内、宽度 ≤72mm；
- 游戏/看剧为主：重量不是首要因素，优先散热和屏幕；
- 已经有腕部不适：重量优先级应当排在参数前面。

## 常见误解

- "越薄越好"：厚度影响握感但不如宽度和重量；
- "轻就是做工差"：轻可能来自更小的电池或塑料中框，要结合配置看；
- "参数表没写重量所以无所谓"：重量是少数几个每天都能感知到的参数。
