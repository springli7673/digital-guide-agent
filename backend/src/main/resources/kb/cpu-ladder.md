# 处理器天梯怎么读

## 天梯分是什么

天梯分是把不同代的手机芯片按综合性能排成一条线，用一个数字表示它的相对位置。
本项目里的 `cpu_score`（40~420）就是按公开天梯图整理的：数字越大，综合性能越强。

## 跑分的三个局限

1. **峰值不等于持续**：跑分通常只跑几分钟，手机预热后就会降频。
   真正影响体验的是"持续性能"，看的是散热面积和调度策略，不是跑分峰值。
2. **不同平台分数不可直比**：跨架构、跨系统的分数经常被厂商宣传成"提升 40%"，
   实际日常使用（刷信息流、拍照、导航）拉不开这么大差距。
3. **跑分不含能效**：一颗芯片可能峰值很高但功耗大，持续高负载下反而更早降频、更烫。

## 怎么按需求看

- **打游戏**：先看持续性能（散热、是否有大面积均热板），再看峰值；
  帧率稳定性比最高帧更重要，掉帧比低帧更影响手感。
- **日常使用**：中端芯片已经够用，流畅度更多取决于内存容量和系统优化。
- **拍照/视频**：ISP 和算法调校比 CPU 峰值更重要。
- **长期使用**：能效比更重要——同样的电池，能效差的芯片续航明显更短。

## 天梯分的用法

用它做**同价位横向对比**，不要用它跨价位下结论：

- 同价位里挑 cpu_score 更高的，通常更划算；
- 但 cpu_score 高不等于整机更好，还要看散热、屏幕、电池；
- 旗舰芯片下放到中端价位（常说的"降频版""青春版"）时，
  要注意它的持续性能可能被散热限制，跑分接近但游戏表现差一截。

## 常见误解

- "核心数越多越强"：大小核架构下核心数说明不了什么；
- "跑分高就打游戏好"：散热和调度不跟上，跑分只是纸面数字；
- "老旗舰不如新中端"：要看具体代际，老旗舰的能效和持续性能经常仍然更好。
