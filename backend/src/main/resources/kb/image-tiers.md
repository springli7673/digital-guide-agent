# 影像梯队分怎么读

## 什么是影像梯队

影像梯队是把机型按**实际影像综合实力**分成几档，本项目的做法是五档，
对应 `image_score` 100 / 85 / 70 / 55 / 40：

- **100（第一梯队）**：影像旗舰，大底主摄 + 潜望长焦 + 成熟算法，长焦和夜景都能打；
- **85（第二梯队）**：影像强，主摄规格高，长焦可用但弱一档；
- **70（第三梯队）**：主流水平，白天成像没问题，弱光和长焦一般；
- **55（第四梯队）**：够用，主摄能出片，副摄多为凑数；
- **40（第五梯队）**：扫码级，光线好时可用。

## 为什么用梯队而不是参数

参数（像素、光圈）只说明硬件潜力，成片质量还取决于算法调校、镜片素质、对焦速度。
同一颗传感器在不同厂商手里能差出一档。梯队分是对"最终出片"的粗略归纳，
用来快速排除明显不符需求的机型，不替代看样张。

## 梯队分适合怎么用

- **筛掉不合适的**：想拍远处（演唱会、风景），直接排除 70 以下；
- **同价位横向比**：同价位里 image_score 更高的通常更值得考虑；
- **不要跨价位硬比**：100 分的机型通常贵一倍，不代表 70 分不能用。

## DXO 分数是什么

DXOMARK 是第三方影像评测机构，会给出一个综合分和细分项（照片、变焦、视频）。
它能提供跨机型的参考，但要注意：

1. **榜单更新滞后**：很多新机没有送测，库里大量 2026 年机型没有 DXO 分；
2. **评分侧重不同**：它的评分权重和你的使用偏好未必一致；
3. **分数差距不等于体验差距**：170 分和 165 分在日常使用中几乎感觉不到差别。

所以本项目的打分里 DXO 权重（0.5）低于影像梯队（1.0）：梯队分覆盖全库，
DXO 只在有数据的机型上作为补充。

## 缺失数据怎么处理

如果用户点名要"拍照好"，而没有 DXO 数据的机型按 0 计入分母——
否则"没被评测过"反而会因为分母小拿到高分。这条规则是为了防止数据缺失变成优势。

## 常见误解

- "像素高影像就好"：见《像素高不等于拍照好》；
- "没有 DXO 分说明影像差"：多数是没送测，不是差；
- "梯队分是绝对的"：它只在这批候选里做相对排序，不是绝对评分。
